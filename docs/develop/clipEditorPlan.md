# 截屏编辑器 · 属性栏与绘制交互计划

本文档规划截屏编辑器的绘制、元素创建和属性编辑。目标是继续使用 Fabric 负责渲染、命中、拖拽和变换，把工具默认值和元素实例属性统一到一块会跟随元素的属性栏。

## 1. 交互规则

### 1.1 工具与属性栏

- 点击工具按钮或按工具快捷键后，属性栏弹出，显示该工具的默认属性。
- 工具默认属性用于下一次创建元素。
- 点击已创建的元素后，属性栏切换为该元素的实例属性，并跟随元素。
- 再次点击工具按钮或按 `Esc`，清空元素选中，属性栏回到当前工具的默认属性。
- 拖拽、缩放、旋转元素时，属性栏持续跟随，不重建内容。
- 属性栏默认不可拖拽，只做自动跟随和贴边翻转。

### 1.2 显示规则

| 状态 | 属性栏 |
| --- | --- |
| 框选模式（`select rect/free`，`drawM(false)`） | 隐藏 |
| 绘制/形状/滤镜工具，未选中元素 | 显示工具默认属性 |
| 绘制/形状/滤镜工具，已选中元素 | 显示元素实例属性，跟随元素 |
| 选择工具（`select draw`），未选中元素 | 隐藏 |
| 选择工具，已选中元素 | 显示元素实例属性，跟随元素 |
| 多选 | 显示属性交集，跟随选区包围盒 |
| 长截屏、保存、隐藏工具栏 | 隐藏 |

“非绘制模式”指框选模式。选择元素属于编辑态，属性栏保持显示。

### 1.3 创建后继续绘制

- 新建元素提交后，自动选中新元素，属性栏显示它的属性。
- 当前创建工具保持激活，可以继续在画布上创建同类型元素。
- 创建工具激活期间：
  - `fabricCanvas.selection = false`
  - `fabricCanvas.skipTargetFind = true`
  - 选中元素的变换控件不参与鼠标命中
- 新元素提交后，属性栏切换到最新元素。
- 切换到选择工具后，恢复 `selection`、`skipTargetFind`，显示变换控件，允许移动、缩放、旋转。

这样“自动选中”和“继续绘制”可以同时成立。

## 2. 副编辑栏与属性栏

### 2.1 副编辑栏

副编辑栏保留工具子类型选择：

- 选择：矩形选择、自由选择、移动
- 绘制：画笔、橡皮、喷刷
- 形状：线条、圆、矩形、折线、多边形、文字、序号、箭头、遮罩
- 滤镜：像素化、模糊、亮度、对比度、饱和度、色调、伽马、噪点等

颜色、填充/描边切换、线宽、画笔阴影、滤镜参数、层级和操作统一由属性栏承担，避免两套属性入口。

### 2.2 属性栏容器

- 新增独立的 `#element_bar`，使用 `Class.glassBar` 的视觉样式。
- 面板使用 `position: fixed`，不放入 `#draw_bar`，避免受固定高度和 absolute 定位限制。
- 复用现有控件：`rangeBar`、`colorInput`、`selectEl`、图标、`.draw_items` 布局。
- 面板标题显示元素类型图标和名称，例如“矩形”“文字”“序号”“箭头”“遮罩”“滤镜 · 马赛克”“画笔”。
- 面板高度按内容变化，最大高度限制在窗口内，超出时内部滚动。

### 2.3 跟随定位

定位基准：

```text
rect = 单选对象的 getBoundingRect()，或多选对象的包围盒并集
screenLeft = (rect.left + editorP.x) * editorP.zoom
screenTop  = (rect.top  + editorP.y) * editorP.zoom
```

放置顺序：

1. 元素右侧
2. 元素左侧
3. 元素下方
4. 元素上方
5. 都放不下时贴窗口边缘，允许部分遮挡

最终坐标 clamp 到窗口内，保留 8px 边距。

防抖动：

- 记住当前方向；元素移动时，当前方向仍放得下就不换边。
- 只有当前方向放不下时才翻转。
- 拖拽、缩放、旋转期间用 `requestAnimationFrame` 合并更新。
- 只更新 `transform: translate3d(...)`，不重建 DOM。
- 面板尺寸变化用 `ResizeObserver` 重新测量并定位。

更新时机：

- `selection:created`
- `selection:updated`
- `selection:cleared`
- `object:moving`
- `object:scaling`
- `object:rotating`
- `object:modified`
- `setEditorP()` 调用后
- `window.resize`
- `showBars()`
- 进入文字编辑、新建拖拽中临时隐藏

鼠标跟随栏的隐藏条件加入 `elementBar.contains(...)`，避免鼠标栏盖住属性栏。

## 3. 属性内容

### 3.1 公共属性

- 位置：X、Y（截图像素）
- 尺寸：宽、高（截图像素）
- 旋转：角度
- 透明度
- 填充、描边、线宽、虚线（按元素类型显示）
- 层级：置顶、上移、下移、置底
- 锁定、复制、删除
- 设为默认

多选时只显示公共外观和操作属性；几何属性在单选时显示。

### 3.2 类型专属属性

| 元素 | 属性 |
| --- | --- |
| 矩形 | 圆角、填充、描边、线宽、虚线 |
| 圆/椭圆 | 填充、描边、线宽、虚线 |
| 线条 | 起点、终点、颜色、线宽、端点样式、虚线 |
| 箭头 | 起点、终点、颜色、线宽、箭头大小、箭头样式、虚线 |
| 画笔/喷刷 | 颜色、粗细、透明度、阴影模糊、阴影颜色 |
| 文字 | 内容、字体、字号、文字颜色、粗体、斜体、下划线、对齐、行高、字距、背景、内边距 |
| 序号 | 数值、自动递增、字号、文字颜色、圆半径、圆填充、圆描边 |
| 折线/多边形 | 节点、填充、描边、线宽、虚线 |
| 遮罩 | 洞口 X/Y/宽/高、圆角、遮罩颜色、透明度 |
| 滤镜 | 滤镜类型、参数、源区域、透明度 |

### 3.3 多选交集

- 所有选中对象都支持的属性才显示。
- 值相同显示实际值；值不同显示“—”。
- 修改后应用到所有支持该属性的对象。
- 混合类型不显示某个类型独有的属性。

## 4. 默认值与实例

- 工具默认属性只用于新建元素。
- 修改选中元素只修改该元素，不写回工具默认值。
- 属性栏提供“设为默认”，显式把当前属性写回默认值。
- 文字、形状、画笔、箭头、序号、遮罩、滤镜分别有自己的默认属性。

## 5. 创建流程

- 矩形、圆、线条、箭头：拖拽创建，实时预览；`Shift` 约束正方形/圆/45°；`Alt` 从中心创建。
- 文字：点击创建并进入编辑；空文字失焦后删除；选择工具下双击文字进入编辑。
- 序号：点击放置，自动递增；再次点击继续；双击结束。
- 折线、多边形：逐点点击；`Enter` 或双击结束；`Backspace` 删除最后一点；`Esc` 取消。
- 遮罩：拖出洞口，遮罩覆盖截图区域。
- 滤镜：拖出区域后应用当前滤镜，自动选中，属性栏可继续调整参数。
- 画笔、橡皮、喷刷：保持连续绘制，`Esc` 或选择工具退出。

所有创建动作提交后只产生一条历史记录。

## 6. 绘制层点击与显示匹配

本节只处理 Fabric 绘制层的鼠标点击位置和显示位置一致。画布显示、整体缩放、平移、框选、外部窗口定位不在本次范围。

### 6.1 根因

- `fabricCanvas` 由 `draw_photo` 初始化，但 `setScreen()` 直接修改 `drawCanvas.width/height`。
- Fabric 的 lower/upper canvas 和内部 `width/height` 没有同步，`upperCanvasEl.width` 与实际画布尺寸不一致。
- Fabric 通过 `upperCanvasEl.width / getBoundingClientRect().width` 计算鼠标缩放，尺寸不一致时点击位置会偏移。
- Fabric 默认 `enableRetinaScaling: true`，而截图 canvas 已经是设备物理像素，背板尺寸会被再乘一次 `devicePixelRatio`。

### 6.2 处理方式

1. 创建 Fabric 画布时关闭 Retina 缩放：

   ```ts
   const fabricCanvas = new Canvas("draw_photo", {
       enableRetinaScaling: false,
   });
   ```

2. 切换屏幕或截图尺寸变化时，通过 Fabric 同步尺寸，不直接改 canvas 元素：

   ```ts
   fabricCanvas.setDimensions({ width: img.width, height: img.height });
   ```

3. 初始化、窗口移动、全屏切换、尺寸变化后调用 `fabricCanvas.calcOffset()`。

4. 保持现有 `editorP` 的 CSS 缩放和画布显示逻辑不变。

5. 增加开发期一致性检查：

   ```text
   fabricCanvas.width === mainCanvas.width
   fabricCanvas.upperCanvasEl.width === mainCanvas.width
   fabricCanvas.upperCanvasEl.getBoundingClientRect().width ≈ mainCanvas.width * editorP.zoom
   ```

### 6.3 验收

- 100%、125%、150%、200% 和全局缩放下，鼠标点击位置与绘制元素位置一致。
- 在画布任意位置画矩形、线条、文字，图形跟随光标，不偏移。
- 画布缩放、平移后，点击仍准确。
- 保存、复制、SVG 导出的元素位置与画布显示一致。
- 偏移问题只在 Fabric 绘制层解决，不修改其他缩放逻辑。
