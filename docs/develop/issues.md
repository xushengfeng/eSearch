# Issue 索引

按模块、关键词和修复提交整理 bug issue，供修复后定位、复测和关闭。

使用方法：

1. 改完代码后，用错误文本、模块名、平台名在本文件搜索，例如 `纯白`、`setIgnoreMouseEvents`、`exitCode 134`、`Wayland`、`长截图`。
2. 对照「修复依据」确认改动进入的版本；还没发布时先不关，等版本发布。
3. 能复测就复测；不能复测时，只关已有明确提交覆盖的条目，存疑的保留。
4. 关闭留言写清提交/版本和验证点；重复的指向主 issue。

关闭话术：

- 已修复：`已在 <commit>（<版本>）修复：<一句话>。如仍能复现，请用 <版本> 重测并附日志，可以重新打开。`
- 重复/合并：`与 #<主 issue> 同根因，合并到 #<主 issue> 跟踪。`
- 信息不足：不要关，补 `需要信息` 标签并指出缺什么。

## 多屏

关键词：多屏、双屏、扩展屏、副屏、截错屏、只识别一个屏、鼠标所在屏、跨屏框选、分辨率不同、multi-monitor、display、screen。

| Issue | 状态 | 说明 |
| --- | --- | --- |
| #167 | open，主 issue | KDE Wayland 三屏只能截主屏。多屏问题统一在这里跟踪，已并入 #212 #409 #443 #464 #498 |
| #481 | open | 贴图无法跨屏；同一根因，但还混着功能请求，暂单独跟踪 |

处理要点：

- 鼠标在哪块屏就截哪块屏，或在截屏按钮处切换屏幕；跨屏框选暂不支持。
- 复测点：各屏分别截屏、分辨率/缩放不一致、截屏按钮切换其他屏幕。
- 不同缩放下的坐标偏移见「缩放 / 清晰度」。

## 保留截屏窗口 / 窗口复用

关键词：保留截屏窗口、第二次截屏、偶数次、无响应、reload、renderer 消失、render-process-gone、webContents destroyed、窗口复用。

| Issue | 状态 | 说明 |
| --- | --- | --- |
| #390 | open，主 issue | Debian/Ubuntu 偶数次点击无反应，关闭「保留截屏窗口」可恢复；已并入 #484 |
| #431 | open | 取消「保留截屏窗口」后重新勾选不生效 |

处理要点：

- #484 的根因：Wayland 下关闭选区后 `hide()` + `reload()` 会让渲染进程消失，但主进程仍保留窗口引用，下一次 `clip_init` 发给失效的 webContents。
- 修复方向：监听 `render-process-gone` / `destroyed` 时置空窗口，或复用前校验 `webContents.isDestroyed()`。
- 复测点：Wayland 下连续触发截屏、Esc 关闭第二次再截、开关「保留截屏窗口」后重启。
