# 保存

截屏、录屏、贴图支持保存。

保存需要你选择保存地址，开启快速保存后，保存到上次保存的位置。

截屏可保存为 PNG、JPG、WebP、BMP、AVIF 和 SVG 格式。

贴图保存格式与截屏默认格式一致，SVG 会保存为 PNG。

录屏可导出为 GIF、WebP、APNG、AVIF、MP4、WebM 和 PNG。

SVG 格式是一种可编辑矢量格式，但保存到文件里的截屏是栅格格式，只有图像编辑产生的形状（除了滤镜外）是矢量格式，便于后期修改。

> [!IMPORTANT]
>
> SVG 是可编辑的，所以会保留图片原始信息，裁切和形状遮挡等可以后期去除，小心不要泄露隐私。

## 复制为文件

在 设置-保存 开启“复制为文件”后，复制图片会写入缓存文件，可以直接粘贴到文件管理器。

## 可通过**eSearch**打开一些图片

安装**eSearch**后，可以在文件管理器 PNG、JPG、WebP、SVG 等图片右键选择打开方式中使用**eSearch**打开。请放心，**eSearch** *不会*修改为*默认*图片打开方式，如果遇到了，请反馈错误。
